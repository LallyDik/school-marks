# מבט — מערכת ציונים והערכה

יישום עברי בכיווניות RTL, המבוסס על Vite ו־Supabase.

## התקנה

המיגרציה הראשונה כבר הורצה על ידי בעל הפרויקט. יש להריץ ב־SQL Editor, לפי הסדר ופעם אחת, את `202611160002_app_access.sql` ואחריו `202611160003_teacher_access.sql` מתיקיית `supabase/migrations`.

בסיום מיגרציה 002 התוצאה כוללת `one_time_setup_code`. שמרו את הקוד באופן פרטי. הירשמו באתר, אשרו את האימייל אם נדרש, התחברו ופתחו "הקמה ראשונית של בית הספר". הזינו את הקוד להפעלת המנהלת הראשונה. אין צורך ליצור משתמשת ידנית. מורות נרשמות באתר וממתינות לאישור מנהלת.

להרצה מקומית:

```powershell
npm.cmd install
npm.cmd run dev
```

כתובת האתר: http://127.0.0.1:5173. הגדרות החיבור נמצאות ב־`.env.local`, המוחרג מ־Git.

## מצב הפיתוח

קיימים מסכי הרשמה והתחברות, איפוס סיסמה, שנות לימוד והיסטוריה, כיתות ומחנכות, תלמידות והעברות בין כיתות, מקצועות, קבוצות ושיבוצים, ציונים ומטלות, הערכות מחנכת, השלמת הזנת קבוצה עם בדיקת חסרים, נעילה ופתיחה מחדש של מחציות ויומן שינויים. קיימים תצוגת תעודה בודדת להדפסה ולשמירת PDF בדפדפן וייצוא Excel עם גיליון לכל כיתה. הרשאות מורות ומחנכות נאכפות באמצעות RLS לפי שיבוץ.

סולמות הציונים ממתינים לאישור הערכים המדויקים כפי שנדרש באפיון. עד לאישור אפשר להזין מטלות וטקסט, אך לא להשלים ציונים.

נותרו: התאמת PDF לדוגמה, הפקת PDF מרוכזת, שמירת עותקי תעודות היסטוריים בלתי משתנים, קידום אוטומטי לשנה הבאה, עריכה מלאה של הישויות, היסטוריית שיבוץ קבוצות, בקרה מפורטת לפי מורה וקבוצה והגדרות גיבוי ופריסה. תעודה היסטורית מחושבת מהנתונים ואינה עותק חתום. החלטת המוכנות לנעילה עדיין בידי המנהלת.

## בדיקות

הוראה בכיתה שלמה: התקינו גם את מיגרציה `202611160006_class_teaching.sql` (אחרי מיגרציה 005 להרשאות מחנכת). במסך השיבוצים בוחרים כיתה, מקצוע ומורה. כל תלמידות הכיתה נכללות אוטומטית, ושינויי רישום מסנכרנים את הרשימה תוך שמירת הציונים הקיימים. הקבצות ממשיכות לקבל שיוך מפורש של תלמידות. מורה מקצועית יכולה להיות משובצת בשתי המסגרות.

ייבוא תלמידות: יש להתקין גם את מיגרציה `202611160004_import_students.sql`. במסך תלמידות אפשר לבחור קובץ XLSX, לבדוק שמות בתצוגה מקדימה ולאשר יצירת תלמידות, כיתות ושיוכים לשנה הנבחרת בפעולה אחת. מספרי זהות משמשים למניעת כפילויות. תלמידות קיימות לא מועברות לכיתה אחרת אוטומטית. שורות לא תקינות מחייבות תיקון או אישור מפורש לדילוג. כתובות וטלפונים בקובץ אינם מיובאים.

```powershell
npm.cmd test
npm.cmd run build
```

בדיקות SQL רצות ב־PostgreSQL בזיכרון באמצעות PGlite עם הדמיית Auth. נבדקים: המיגרציות, קוד הקמה חד־פעמי, הפרדת הרשאות, חסימת הסלמת הרשאות, שייכות לקבוצה, השלמת הזנה וביטולה לאחר שינוי, נעילה ויומן שינויים. טרם בוצעה בדיקת קצה לקצה מול Supabase המרוחק.

אין לשים מפתח service_role בדפדפן. סיסמאות ינוהלו באמצעות Supabase Auth בלבד.
